**Issue:** An experimental visual setting gave visitors control over a purely decorative treatment with no user task behind it.

**Suggested improvement:** In the Process section, require every added control to state the user task it enables; use static presentation for aesthetic decisions that do not need a visitor choice.

**Principle:** User controls should create meaningful agency, not transfer incidental design decisions to the user.
