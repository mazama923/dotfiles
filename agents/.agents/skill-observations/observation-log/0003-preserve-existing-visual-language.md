**Issue:** A UX refinement improved readability but replaced the existing mechanical visual language instead of evolving it.

**Suggested improvement:** Add a pre-implementation design inventory to the Process section: record the product visual motifs, interaction cues, and accessibility constraints that the refinement must preserve.

**Principle:** Improve usability by clarifying an existing identity; do not substitute a new aesthetic unless a redesign is explicitly requested.
